fleet-filter

A reverse proxy that refuses known exploit requests before they reach the origin server — and publishes the evidence for every exploit it claims to stop.

Most web servers cannot be patched the moment a CVE lands, and a CVE with public exploit code is being used within hours. fleet-filter sits in front of the origin, recognises the request shapes those exploits use, and refuses them. It does not try to be a general-purpose WAF: it holds a small set of signatures, each tied to a named vulnerability and a recorded demonstration.

What it does

  • Refuses known exploit shapes at the proxy — path traversal, request smuggling, deserialisation markers, upload-progress payloads — before the request reaches the application.
  • Bounded deception: a probe that is not a known exploit can be answered by a tarpit that holds the connection and wastes the attacker's time. Bounded on purpose, so it cannot be turned into a denial of service against you.
  • An evidence ledger. Every entry names a CVE, records the exploit run without the control, then the same run through it, and states a verdict: blocked, neutralised, unverified or uncovered. Entries whose evidence does not exist are marked, not quietly upgraded.

Install from source

cargo build --release --manifest-path gateway/Cargo.toml
./target/release/fleet-filter-gateway --help

Configuration is a single TOML policy bundle: listener, TLS material, the signature store, the detection mode, and the upstream. Signed policy distribution is built in — a host verifies a detached RSA signature over the policy digest with a key provisioned out of band, before the policy is parsed.

The ledger is the point

VerdictMeans
blockedthe exploit works without the control and fails through it, recorded
neutralisedthe attack succeeds but delivers nothing useful through it
unverifiedan entry exists, the evidence does not
uncovereda known exploit this proxy does not stop

Publishing the uncovered ones is deliberate. A security tool that only lists its successes is selling, not reporting.
